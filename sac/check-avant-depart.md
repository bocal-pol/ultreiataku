# Check avant départ — Rétroplanning

## J-90 (3 mois avant départ)

### Matériel
- [ ] Décision date de départ ferme
- [ ] Achat sac à dos (essayer chargé 5 kg en magasin)
- [ ] Achat chaussures rando (2 tailles au-dessus habituel — pieds gonflent)
- [ ] Achat sac de couchage + matelas
- [ ] Achat tente (si bivouac 50%+)

### Physique
- [ ] Bilan médical (cardio + articulaire + vaccins tétanos à jour)
- [ ] Début programme entraînement 3 sorties/semaine
- [ ] Renforcement dos + fessiers + mollets démarré

### Administratif
- [ ] **Retirer la credencial** à Liège (Cathédrale Saint-Paul) ou par Association Belge des Amis de Saint-Jacques
- [ ] Vérifier validité CI (au moins 6 mois après retour prévu)
- [ ] Demander carte européenne d'assurance maladie (CEAM) à ta mutualité
- [ ] Souscrire assurance rapatriement (Mutualité, AXA, Allianz — 50-80 €/an)

---

## J-60 (2 mois avant départ)

### Matériel
- [ ] Achat réchaud + popote + gourdes + filtre eau
- [ ] Test tente : monter + démonter en jardin, dormir 1 nuit
- [ ] Test réchaud : allumer 3 fois, préparer un repas
- [ ] Achat vêtements techniques (mérinos, hardshell, sur-pantalon pluie)
- [ ] Achat bâtons de marche

### Physique
- [ ] Sorties 12-15 km avec sac 5-7 kg
- [ ] Chaussures rodées (25-40 km cumulés)
- [ ] Renforcement continu 3×/semaine

### Administratif
- [ ] Préparer photocopies documents importants
- [ ] Backup numérique documents dans drive cloud
- [ ] Notifier proches du plan de voyage

---

## J-30 (1 mois avant départ)

### Matériel
- [ ] Sortie test 25 km avec sac plein (11-12 kg)
- [ ] Test bivouac complet : tente + réchaud + repas + nuit
- [ ] Ajustements matériel selon retour terrain
- [ ] Kit pharmacie complet préparé et testé
- [ ] Cartes offline téléchargées (Belgique + Ardennes FR)
- [ ] GPX de la Voie Mosane + Monastique téléchargée depuis calculitineraires.fr ou verscompostelle.be

### Physique
- [ ] Chaussures rodées à 100 km cumulés minimum
- [ ] Test dos + hanches confirmé (portage 10 kg 4h sans douleur)
- [ ] Continuer entraînement, préparation tapering

### Administratif
- [ ] Numéros d'urgence enregistrés téléphone + papier (contacts + ambassade)
- [ ] Ordonnances traitements chroniques renouvelées
- [ ] Communication : forfait roaming actif, WhatsApp/Signal testés
- [ ] Photocopies + backup à jour
- [ ] Cash retiré (300-400 €), en 3 poches

---

## J-14 (2 semaines avant départ)

### Matériel
- [ ] Vérifier météo J-14 avec Windy / IRM
- [ ] Ajuster matériel selon prévisions (moins ou plus de polaire selon T°)
- [ ] Ravitaillement initial J1-J2 acheté sec (fruits secs, chocolat, biscuits secs)
- [ ] Kit pieds re-vérifié (Compeed, Nok, sparadrap complet)

### Contacts
- [ ] Prévenir gîte J1 (Amay paroissial) — arrivée + horaire
- [ ] Vérifier disponibilités Grotte Scladina (si passage 1er dimanche du mois)

### Physique
- [ ] Tapering : sorties réduites 50%, focus récupération
- [ ] Sommeil ++ (8h)
- [ ] Nutrition prépa (glucides complexes, hydratation)

---

## J-7 (1 semaine avant départ)

- [ ] Météo J-7 vérifiée (Windy)
- [ ] Ravitaillement J1-J2 acheté
- [ ] Sac préparé et pesé — objectif ≤ 12 kg total
- [ ] Test dernière fois : sortir 30 min avec sac plein, ressenti final
- [ ] Confirmer gîte J1 par appel
- [ ] Vérifier météo J1-J3
- [ ] Recharger tous les appareils (batterie externe, téléphone, frontale)

---

## J-1 (veille du départ)

- [ ] **Sac pesé une dernière fois** (≤ 12 kg avec 1 L d'eau)
- [ ] Douche complète + coupe ongles pieds + chaussettes propres
- [ ] Repas riche en glucides (pâtes/riz + protéines + légumes)
- [ ] Hydratation ++
- [ ] **Coucher tôt** (22h max)
- [ ] Alarme réglée pour départ 7h
- [ ] Passer à la Cathédrale Saint-Paul pour dernier tampon credencial
